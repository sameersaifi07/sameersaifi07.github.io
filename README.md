# Sameer Saifi — Portfolio

A plain HTML/CSS/JS version of the Framer portfolio. No build step is needed.

## Edit
Open `index.html` in any editor.

- **Links and email:** the `CONFIG` block near the bottom of the file holds the booking link, email, X, TikTok and Instagram links.
- **Text:** search for the words you want to change and replace them.
- **Images:** replace the files in `assets/` and keep the same names:
  - `hero.webp`
  - `about.webp`
  - `featured-poster.webp`
  - `clients/client-1..6.webp`
  - `logo.svg`
- **Work cards:** each card in the "Selected Work" section has its own video URL, link, title and tags.

## Put it online (GitHub Pages)
1. Create a new repository. If you name it `sameersaifi07.github.io`, the site lives at that address.
2. Upload everything inside this folder: `index.html`, `assets/`, `.nojekyll` and `README.md`.
3. In the repository, open **Settings → Pages → Branch: main → Save**.
4. Wait 1–2 minutes, then open the link.
